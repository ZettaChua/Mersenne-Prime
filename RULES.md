# Project Rules (v0.1)

Purpose  
This network exists to reward real, verifiable contribution.

Consensus  
Blocks are created through collective contribution. All valid contributors are rewarded proportionally.

Work  
Work must be deterministic, verifiable, and costly to perform but cheap to verify.

Fairness  
There are no mining pools, lotteries, or privileged participants.

Supply  
Total supply is capped. Coins are issued only through block rewards.

Openness  
The protocol is open-source and publicly auditable.

No Pre-Allocation  
There is no premine, presale, or private allocation.

Longevity  
The system is designed to operate independently for decades.
